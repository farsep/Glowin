# 🌟 Glowin

**Brilla con estilo** ✨  
Glowin es una aplicación web desarrollada para la gestión de un centro de estética. Permite la administración de turnos, usuarios y servicios de manera eficiente.
Es una plataforma digital que conecta usuarios con salones de belleza, simplificando la reserva de turnos y mejorando la experiencia en la industria de la belleza.




---

## 🚀 Tecnologías
### Backend
- **Lenguaje**: Java 23
- **Frameworks**: Spring Boot 3.4.2
- **Base de datos**: PostgreSQL + Flyway (migraciones)
- **APIs**: Swagger (OpenAPI)
- **Seguridad**: JWT (JSON Web Tokens)
- **Email**: Spring Mail (SMTP)

### Frontend
- React + Material UI
- HTML/CSS
- JavaScript

### DevOps & Infraestructura
- **Contenedores**: Docker
- **Orquestación**: Docker Compose
- **Cloud**: AWS
- **IaC**: Terraform
- **CI/CD**: GitLab

### Gestión
- **Metodología**: Scrum (Trello, Discord)
- **Testing**: Google Suite
